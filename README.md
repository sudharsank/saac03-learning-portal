# SAA-C03 Study Portal

A focused self-study portal for the **AWS Certified Solutions Architect – Associate** certification exam.

## Features

- Structured lessons across all exam domains
- Practice quizzes with instant feedback
- Progress tracking (localStorage — no account required)
- Mock exam simulator
- Curated community resources

## Development

```bash
npm install
npm run dev
```

## Deployment

Push to `main` — GitHub Actions deploys to GitHub Pages automatically.

Live at: `https://sudharsank.github.io/saac03-learning-portal/`
